🍽️ Partania’s Restaurant Admin Dashboard

This is a 5-star restaurant admin dashboard built to manage daily operations in a clean, elegant way.
The focus is on clarity, usability, and a luxury feel — not clutter.

This project is UI-first and designed to look like a real restaurant admin system you’d actually use.

✨ What’s Included

Admin dashboard layout

Loyalty & points tracking

Membership tiers (Bronze → Platinum)

Points to next level display

Recent activity summary

Card-based UI with luxury styling

Desktop-first admin design

🛠 Tech Used

React

JavaScript

Vite

Custom CSS (no UI libraries)

🎯 Why I Built This

I wanted to practice building real-world admin dashboards — the kind restaurants actually need — while keeping the design polished and professional.
